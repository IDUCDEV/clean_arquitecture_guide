# 11 — Recursos para Seguir Practicando

> La clave no es "saber" sino **practicar**. Aquí tienes los mejores recursos ordenados por tipo.

---

## 🎯 Plataformas interactivas (recomendadas)

| Plataforma | Por qué usarla | Para empezar |
|------------|----------------|-------------|
| **[Dartpad](https://dartpad.dev)** | Editor oficial de Dart en el navegador. Sin instalación. | Crea un snippet y experimenta con cada método |
| **[Exercism Dart Track](https://exercism.org/tracks/dart)** | 100+ ejercicios con mentoría gratuita. **El mejor recurso para aprender Dart en serio.** | Empieza por "Hello World" y sube de nivel |
| **[Codewars](https://www.codewars.com)** | Kata (ejercicios) de 1-kyu a 8-kyu. Competitivo y adictivo. | Filtra por Dart, empieza con 7-kyu (fáciles) |
| **[LeetCode](https://leetcode.com)** | El estándar de entrevistas técnicas. | Filtra por Dart, problemas "Easy" de Array/HashMap |
| **[Advent of Code](https://adventofcode.com)** | 25 problemas cada diciembre. Escalada de dificultad perfecta. | Resuelve en Dart, excelente para pensar algoritmos |

### 📊 Roadmap recomendado

```
1. Exercism Dart Track → 30 ejercicios (fundamentos sólidos)
2. Codewars → 20 katas nivel 7-kyu (colecciones y maps)
3. LeetCode → 10 problemas Easy Array/HashMap (pensamiento algorítmico)
4. Advent of Code → Año anterior completo (problemas complejos del mundo real)
5. Vuelve a Exercism → ejercicios difíciles (mentoría)
```

## 📝 Rutina diaria sugerida

```
🎯 15 minutos al día (no más, no menos)

Días 1-10:  Exercism → 1 ejercicio + entender la solución
Días 11-20: Codewars → 1 kata + leer soluciones de otros
Días 21-30: LeetCode → 1 Easy + pensar en performance (O(n))
Días 31+:    Alterna entre proyecto personal y Advent of Code
```
