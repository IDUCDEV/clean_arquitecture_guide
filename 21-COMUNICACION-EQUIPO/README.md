# Modulo 21: Comunicacion y Trabajo en Equipo

## Por que las soft skills importan para un developer

El codigo perfecto no sirve de nada si no puedes comunicar tus ideas, colaborar con tu equipo
o entender las necesidades del producto. Los developers que mejor pagan no son los que escriben
el mejor codigo — son los que mejor **comunican**, **colaboran** y **trabajan en equipo**.

Este modulo te ensena las habilidades blandas que separan a un junior de un senior:
code reviews efectivos, comunicacion tecnica, colaboracion con diseno y producto,
y las herramientas que mantienen al equipo sincronizado.

> **Nota:** Este modulo es agnostico a tecnologia pero usa ejemplos de Flutter y Git
> porque son los herramientas de nuestro stack principal.

## Lo que NO cubre este modulo

| Tema | Por que no | Donde buscar |
|------|-----------|-------------|
| Leadership tecnico | Requiere experiencia senior+ | Libros: "Staff Engineer", "The Manager's Path" |
| Gestion de proyectos | No es nuestro enfoque | PMP, Scrum.org, Agile Alliance |
| Negociacion salarial | Tema diferente | Glassdoor, Levels.fyi, coaches de carrera |
| Presentaciones ejecutivas | Habilidad especifica | Toastmasters, libros de presentaciones |
| Mentororia formal | Requiere rol de mentor | Programas internos de la empresa |
