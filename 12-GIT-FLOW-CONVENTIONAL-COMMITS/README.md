## 🎯 ¿Por qué este módulo?

Un proyecto profesional no solo tiene buen código, sino **buenas prácticas de equipo**:

| Problema | Solución |
|----------|----------|
| Commits sin contexto (`fix`, `update`, `cambios`) | Conventional Commits |
| Código que no pasa análisis al commitear | Husky + lint-staged |
| Mensajes de commit inconsistentes | Commitizen |
| Versiones de Flutter diferentes entre devs | FVM |
| Ramas desordenadas sin estrategia | Git Flow / GitHub Flow |
