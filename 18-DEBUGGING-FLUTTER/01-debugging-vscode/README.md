# Submodulo 1: Debugging con VSCode

## Descripcion

Domina el debugger integrado en Visual Studio Code para Flutter. Aprende a configurar `launch.json`, usar todos los tipos de breakpoints, inspeccionar datos en tiempo real y resolver bugs complejos en aplicaciones reales.

## Que aprenderas

- Iniciar y detener sesiones de debugging con F5
- Configurar `launch.json` para Android, iOS, Web, Desktop
- Usar breakpoints basicos, condicionales, triggered, inline, data y logpoints
- Inspeccionar variables y evaluar expresiones en Debug Console
- Debugging multi-target (frontend + backend)
- Resolver bugs reales en escenarios con BLoC, Supabase, GoRouter

## Atajos esenciales (记忆 rapida)

| Accion | Atajo |
|---|---|
| Iniciar debugging | `F5` |
| Pausar/Continuar | `F5` (toggle) |
| Step Over | `F10` |
| Step Into | `F11` |
| Step Out | `Shift+F11` |
| Toggle Breakpoint | `F9` |
| Detener | `Shift+F5` |
| Restart | `Ctrl+Shift+F5` |
