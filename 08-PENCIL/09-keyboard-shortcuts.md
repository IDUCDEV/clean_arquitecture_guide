# Keyboard Shortcuts

> Referencia completa de todos los atajos de teclado de Pencil, organizados por categoría. Imprime esta página, pégala al lado de tu monitor y apréndelos de a 3 por día.

---

## Herramientas

| Atajo | Herramienta |
|---|---|
| `V` | Move (selección y movimiento) |
| `H` | Hand (mano para desplazar canvas) |
| `A` / `F` | Frame (contenedores) |
| `R` | Rectangle |
| `O` | Ellipse |
| `T` | Text |
| `N` | Sticky Note |

---

## Selección

| Atajo | Acción |
|---|---|
| `Cmd/Ctrl + A` | Seleccionar todos los elementos |
| `Cmd/Ctrl + clic` | Selección directa (elemento más profundo bajo el cursor) |
| `Shift + clic` | Añadir/quitar elemento de la selección |
| `Shift + Enter` | Seleccionar el padre del elemento actual |
| `Enter` | Seleccionar el hijo del elemento actual |
| `Esc` | Limpiar selección |

---

## Edición

| Atajo | Acción |
|---|---|
| `Cmd/Ctrl + C` | Copiar selección |
| `Cmd/Ctrl + V` | Pegar |
| `Cmd/Ctrl + X` | Cortar |
| `Cmd/Ctrl + D` | Duplicar selección |
| `Delete` / `Backspace` | Eliminar selección |
| `Cmd/Ctrl + G` | Agrupar elementos seleccionados |
| `Cmd/Ctrl + Shift + G` | Desagrupar |
| `Cmd/Ctrl + Option/Alt + G` | Aplicar flex layout a la selección |
| `Cmd/Ctrl + [` | Enviar atrás (bajar una capa) |
| `Cmd/Ctrl + ]` | Traer adelante (subir una capa) |
| `[` | Enviar al fondo |
| `]` | Traer al frente |
| Flechas direccionales | Mover selección 1px |
| `Shift` + Flechas | Mover selección 10px |
| `Cmd/Ctrl + Z` | Deshacer |
| `Cmd/Ctrl + Shift + Z` | Rehacer |

---

## Componentes

| Atajo | Acción |
|---|---|
| `Cmd/Ctrl + Option/Alt + K` | Convertir selección a componente / Revertir componente a elemento |
| `Cmd/Ctrl + Option/Alt + X` | Detach (desvincular instancia del componente origen) |

---

## Canvas

| Atajo | Acción |
|---|---|
| Space + Arrastrar | Pan (desplazar canvas) |
| Botón medio del mouse + Arrastrar | Pan alternativo |
| `Cmd/Ctrl` + Scroll | Zoom in / out |
| `Shift` + Scroll | Desplazamiento horizontal |
| `=` | Zoom in |
| `-` | Zoom out |
| `0` | Zoom al 100% |
| `1` | Zoom to fit (ver todo el contenido) |
| `2` | Zoom to selection (zoom al elemento seleccionado) |

---

## Canvas Settings

| Atajo | Acción |
|---|---|
| `Cmd/Ctrl + '` | Toggle pixel grid (mostrar/ocultar cuadrícula de píxeles) |
| `Cmd/Ctrl + Shift + '` | Toggle snap to pixel grid (ajustar a cuadrícula) |

---

## AI Chat

| Atajo | Acción |
|---|---|
| `Cmd/Ctrl + K` | Abrir/cerrar el panel de AI chat |
| `Cmd/Ctrl + T` | Nueva pestaña de agente |
| `Ctrl + Tab` | Siguiente pestaña de chat |
| `Ctrl + Shift + Tab` | Pestaña anterior de chat |
| `↑` / `↓` | Navegar historial de prompts |

---

## Archivo

| Atajo | Acción |
|---|---|
| `Cmd/Ctrl + S` | Guardar archivo |
| `Cmd/Ctrl + N` | Nuevo archivo |
| `Cmd/Ctrl + O` | Abrir archivo |
