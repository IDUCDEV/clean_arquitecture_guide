## 🎯 Contenido

### Framework AIDR
- **A**nalyze: Analiza tú primero el problema
- **I**nvestigate: Investiga con IA patrones y soluciones
- **D**ecide: Decide qué va a IA y qué haces tú
- **R**eview: Revisa y valida todo lo que generó IA

### Estrategias por capa
- Domain: Entity, Repository Interface → IA; UseCases, Validaciones → Tú
- Data: Models, DataSources → IA; Repository Implementation, Cache → Tú
- Presentation: Estados de Cubit → IA; Validación de formularios → Tú
- Testing: Scaffold de tests → IA; Aserciones, Edge cases → Tú
