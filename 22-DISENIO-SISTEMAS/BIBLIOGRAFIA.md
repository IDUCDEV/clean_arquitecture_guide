# Bibliografía

> Fuentes principales de este módulo, con el motivo de su inclusión. Formato: autor — título — motivo.

---

## Libros

- **Martin Kleppmann** — *Designing Data-Intensive Applications* — La referencia definitiva sobre datos distribuidos: replicación, particionado, transacciones, consistencia. Base teórica de los archivos 04, 07 y 14.
- **Alex Xu** — *System Design Interview (Vol. 1 y 2)* — Framework de entrevistas y casos resueltos paso a paso. Base de la plantilla del archivo 11 y del Nivel 4 del archivo 16.
- **Donne Martin** — *The System Design Primer* — Compendio gratuito de todo lo que un system designer necesita: conceptos, trade-offs, casos. Es la columna vertebral del curso (usado como fuente primaria en 00-10).
- **Brendan Gregg** — *Systems Performance* — Métricas y metodología USE para diagnóstico de rendimiento. Referencia puntual del archivo 09.

---

## Documentación oficial

- **Supabase Docs** — *Database / Realtime / Auth / Functions / Telemetry* — Documentación del stack del repositorio; usada para RLS (03), Realtime (06), seguridad (08) y observabilidad (09).
- **Saltzer & Schroeder** — *The Protection of Information in Computer Systems* — Paper clásico del principio de menor privilegio (archivo 08).
- **OWASP** — *OWASP Top 10* — Marco de riesgos de seguridad en aplicaciones web (archivo 08).

---

## Artículos y guías en línea

- **ByteByteGo** — *Caching strategies, CAP theorem, Short/long polling vs SSE vs WebSocket, Timeouts & Retries, Observability, Chat/E-commerce/Multi-tenant designs* — Diagramas y explicaciones concisas que sustentan los archivos 05, 06, 07, 09, 12, 13, 14 y 15.
- **Brendan Gregg** — *The USE Method* — Guía corta de métricas de rendimiento (archivo 09).

---

## Criterio de inclusión

1. Todo lo citado se **usó** en algún archivo de este módulo (nada decorativo).
2. Se priorizaron fuentes **libres/gratuitas** (System Design Primer, docs oficiales, ByteByteGo, papers clásicos).
3. Los libros (Kleppmann, Xu) aparecen como **profundización**, no como requisito para empezar.
