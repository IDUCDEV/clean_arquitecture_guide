## 5. Herramientas de debugging

### Flutter Inspector
```
Qué es: Herramienta integrada en VS Code/Android Studio
Para qué: Inspeccionar widgets, ver estructura, debuggear UI
Cómo acceder: Ctrl+Shift+P → "Flutter: Open Flutter Inspector"
```

### Dart DevTools
```
Qué es: Suite de herramientas de debugging
Para qué: Performance, memoria, logs, widget inspector
Cómo acceder: Ctrl+Shift+P → "Dart: Open DevTools"
```

### Debugging en VS Code
```
Atajos útiles:
- F5: Iniciar debugging
- F9: Toggle breakpoint
- F10: Step over
- F11: Step into
- Ctrl+Shift+F5: Restart
```

## 7. Cómo evaluar si una fuente es confiable

### Señales de fuente confiable
- ✅ Autor identificado con experiencia verificable
- ✅ Contenido actualizado (menos de 1 año)
- ✅ Código de ejemplo funciona
- ✅ Otros desarrolladores lo recomiendan
- ✅ Está en la documentación oficial o es citado por ella

### Señales de fuente no confiable
- ❌ Autor anónimo sin reputación
- ❌ Contenido antiguo (> 2 años sin actualizar)
- ❌ Código con errores
- ❌ No hay referencias a fuentes oficiales
- ❌ Solo tiene opiniones, no datos

## 8. Plan de estudio recomendado

### Si eres principiante
```
1. Flutter Docs: Get Started
2. Dart Docs: Language tour
3. Flutter Cookbook: Recetas comunes
4. Un tutorial completo (Reso Coder o similar)
5. Practica con los ejercicios de este módulo
```

### Si eres intermedio
```
1. Clean Architecture (blog post original)
2. BLoC Library docs
3. Supabase docs (si usas Supabase)
4. Flutter testing docs
5. Práctica con features intermedias
```

### Si eres avanzado
```
1. Arquitectura de apps grandes (GitHub repos)
2. Performance optimization (Flutter docs)
3. Testing patterns avanzados
4. Contribuir a open source
5. Mentorear a otros
```
